# Open Bible

A private, web-based Catholic Bible reader with a split view: Scripture on one side and your notes on the other. It tracks reading progress automatically and keeps highlights and notes behind a single-user login, so they are available on any device.

**Status:** planning.

| Doc | What's in it |
|---|---|
| [`docs/PLAN.md`](docs/PLAN.md) | Scope, translation/licensing decision, UX behavior, stack, data model, API, milestones, open questions |
| [`docs/wireframes.html`](docs/wireframes.html) | Low-fi wireframes: sign in, reader (scroll and page), highlight/note flow, book picker, progress, mobile |
| [`docs/mockup.html`](docs/mockup.html) | Interactive hi-fi reader mockup. Open it in a browser: select text to highlight, click a verse number to add a note, toggle Scroll/Page, drag the divider |

Mockup text is the public-domain Douay-Rheims and serves only as a placeholder. The app will use a USCCB-approved translation (NABRE proposed) once licensing is sorted. See PLAN §2.
